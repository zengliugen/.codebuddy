# 检查口径

本文件定义覆盖率统计的分子、分母、层级与豁免规则。

## 1. 分母：统计哪些成员

| 维度 | 默认口径 |
|------|---------|
| 访问级别 | `public` + `internal`（经 `memberScope.accessibilities` 配置） |
| `private` 成员 | **默认不纳入**（`includePrivateMembers: false`） |
| 嵌套类型 | 纳入（`includeNestedTypes: true`） |
| 枚举值 | 纳入（`includeEnumValues: true`） |
| 编译器生成成员 | 跳过（`skipCompilerGenerated: true`） |
| 属性访问器 | 纳入（`skipPropertyAccessors: false`） |
| 事件访问器 | 跳过（`skipEventAccessors: true`） |
| 运算符重载 | 纳入（`skipOperators: false`） |
| 析构函数 | 跳过（`skipDestructors: true`） |

**理由**：`private` 成员通常只被同类内部调用，纳入分母会稀释覆盖率数值；而 `internal` 成员常被同程序集测试直接调用，属于有效被测面。

## 2. 分子：什么算「已覆盖」

### 2.1 强引用（计入已覆盖）

| 引用形式 | 示例 |
|---------|------|
| 实例方法调用 | `queue.Enqueue(0)` |
| 静态方法调用 | `ExampleType.Create(ref allocator, s)` |
| 构造调用 | `new Queue<Int32>(4)` |
| 属性读取 | `queue.Capacity` |
| 公开字段读取 | `queue.Data` |
| 索引器 | `array[memoryAllocator, i]` |
| 泛型实例化 | `Queue<Int32>`、`Comparer<Int32>.Create(...)` |
| 嵌套类型 + 枚举值 | `ExampleCollection<Int32,Int32>.EInsertionBehavior.OverwriteExisting` |
| **`foreach` 隐式 `GetEnumerator`** | `foreach (var x in queue)` |
| **`Assert.Throws<T>` 中的 T** | `Assert.Throws<ArgumentException>(...)` |
| **`typeof(T)`** | `typeof(ExampleType)` |
| **`default(T)`** | `default(ExampleType)` |
| 显式类型转换 | `(ExampleType)value` |
| lambda 作为委托实参 | `list.ForEach(allocator, v => ...)` |
| 泛型类型出现在签名 | `private static ExampleCollection<Int32> CreateArray(...)` |
| `in` / `ref` 参数 | `source.Add(ref allocator, 1, 10)` |
| 运行时特性 | `[MemoryCopy]` |
| 继承运行时类型 | `class Foo : MemoryCopyConfig` |
| 扩展方法 | `array.AsSpan(allocator)` |
| `nameof(...)` | `nameof(Queue.Enqueue)` |
| 裸方法组 | `list.ForEach(this.Handle)` |
| **运算符重载调用** | `a + b`、`a << 2`、`-a`、`a++`、`a += b`、`a == b` |
| **显式/隐式转换运算符** | `(Single)ffloatValue`、`SecurityInt32 x = 5` |
| **条件真值运算符** | `if (a)` / `while (a)` 中的 `operator true` |

> **运算符采集的实现约束（实测结论）**：运算符调用在语法树上的可绑定位置**极不统一**，
> 因此统一从 **Roslyn 操作树**采集（`IBinaryOperation` / `IUnaryOperation` /
> `ICompoundAssignmentOperation` / `IConversionOperation` / `IIncrementOrDecrementOperation` 的
> `OperatorMethod`），不按语法节点逐个分支：
>
> | 形式 | 语法节点能否绑定 | 说明 |
> |------|-----------------|------|
> | 二元 / 一元 / 复合赋值 / 自增自减 | 能（`GetSymbolInfo` 可用） | `a + b` → `op_Addition` |
> | 显式转换 | 能 | `(Single)a` → `op_Explicit` |
> | **隐式转换** | **多数不能** | 分散在变量初始化、赋值、实参、返回、数组元素等十余处，`GetSymbolInfo` 通常取不到 |
> | **`operator true` / `false`** | **不能** | 只在外层语句（`if`/`while`/`for`/`?:`/`&&`/`||`）的 `Condition` 子操作里可见；直接对条件表达式取 `GetOperation` 会退化为 `LocalReference` |
>
> 另需**按「运算符文档 ID + 语法位置」去重**：同一节点的操作树与其祖先节点的操作树互相包含
> 同一子操作，直接遍历会重复计数（实测某样本原始 44 次命中，实为 8 个转换点）。

### 2.2 弱引用（单列，不计入已覆盖）

| 形式 | 示例 | 为何算弱 |
|------|------|---------|
| XML `cref` | `/// <see cref="CacheDictionary{TKey,TValue}.Remove"/>` | 文档引用，不产生调用 |
| 反射字符串成员名 | `GetField("mSlotIndex", ...)` | 字符串可能失效，且不保证执行 |

**配置开关**：`referenceStrength.countWeakAsCovered`（默认 `false`）。开启后弱引用计入已覆盖，会显著抬高覆盖率数值，**不建议**。

弱引用在报告中单列，用于区分「完全没提到」与「提到了但未真实调用」。

## 3. 统计层级

报告以**成员级**为底，向上逐级汇总：

| 层级 | 计算方式 |
|------|---------|
| 成员级 | 该成员是否有强引用 |
| 类型级 | 该类型下已覆盖成员数 / 成员总数 |
| 文件级 | 该文件下已覆盖成员数 / 成员总数 |
| 程序集级 | 该程序集下已覆盖成员数 / 成员总数 |

**判定「零测试文件」**：该文件下**所有**成员均无强引用（弱引用不计）。这类文件在报告中单列，优先级高于单个未覆盖成员。

## 4. 豁免规则

### 4.1 不计入分母

| 对象 | 判定方式 |
|------|---------|
| `Generated/`、`Gen/` 目录 | 路径含 `/Generated/` 或 `/Gen/`（大小写不敏感） |
| auto-generated 文件 | 文件头**前 5 行**含 `<auto-generated` 或 `<auto generated`（大小写不敏感，支持行内任意位置） |
| 三方库目录 | 由 `exclude.paths` 声明的各路径分量匹配 |
| `Library/PackageCache/` | 路径含 `/Library/PackageCache/`（Unity 包缓存） |

**注意**：auto-generated 标记**只认文件头部区域**。不要全文搜索——手写的代码生成器文件会因全文 grep 命中，但它不应被豁免。

### 4.2 生成代码的不对称处理

| 对象 | 处置 | 理由 |
|------|------|------|
| 生成的**运行时**代码（`Runtime/Gen/**`、`Runtime/Generated/**`） | **豁免，不计入分母** | 生成器产物不由手写测试覆盖 |
| 生成的**测试**代码（`Tests/**/Gen/**`） | **计入分子** | 是真实执行的 `[Test]`，排除会显著低估覆盖率 |

本项目 `fixedmathematics` 包的生成测试含 549 个 `[Test]`，占该包用例总数约 68%——排除会造成严重低估。

## 5. 引用与分母的对应关系

```
运行时源码（`Runtime/` + 各业务领域目录，按配置 `runtimeRoots`）
  └── 采集 public + internal 成员  →  分母
测试代码（Tests/）
  └── 采集符号引用  →  分子
      ├── 强引用 → 已覆盖
      └── 弱引用 → 单列
```

**约束**：运行时成员**只从运行时目录采集**。`Tests/Runtime/**` 下的测试替身类型（如 `ExampleType.cs`）不能作为运行时成员计入分母，但它们对运行时类型的继承与特性标注是**真实引用**，应计入分子。

## 6. `[Test]` 的识别约束

`[Test]` / `[TestCase]` **必须用 `AttributeSyntax` 判定**，禁止字符串匹配。

反例：本项目 `fixedmathematics/Runtime/Core/Generator/CodeGenerator.cs` 与 `CodeGenerator.ApiCompleteness.cs` 中含 `"[Test]"` 字符串字面量（生成器模板），文本匹配会将其误计为测试。
