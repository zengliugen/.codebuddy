## 2026-10-29 项目根锚点去掉 .git（独立仓库形态下根定位错误）

| 项 | 内容 |
|---|---|
| 文件 | `scripts/skill_config.py` 的 `_find_project_root()` |
| 问题 | 原实现把 `.codebuddy` 与 `.git` 并列为项目根锚点。引擎以**独立 git 检出**形态挂载时 `.codebuddy/.git` 是目录，向上查找**先命中 `.codebuddy` 自身**，项目根被误判为 `.codebuddy`，配置路径随之拼成 `.codebuddy/.codebuddy.project/...`，技能完全读不到项目侧配置，报「未找到项目侧覆盖率配置」 |
| 为什么没早发现 | 本引擎仓库为 submodule 形态，`.codebuddy/.git` 是 gitfile（文件），`os.path.isdir()` 不成立，向上查找碰巧越过 `.codebuddy` 命中真正的项目根——同样的代码在两种挂载形态下行为相反 |
| 补丁 | 只认 `.codebuddy` 子目录作锚点，命中即返回该目录；删除 `.git` 锚点判断 |
| 影响面 | 同型缺陷全库共 7 处，已一并修正（本包 2 处，其余 5 处分布在代码审查、开发流程与 Python 工具类技能中，各自在自己的变更记录里留痕） |
| 验证 | 临时把 `.codebuddy/.git` 伪装成目录（模拟独立仓库形态），7 个脚本的 `find_project_root` 全部返回真实项目根；恢复形态后复查通过 |
| 升级注意 | 引擎若改挂载形态约定，需重新确认此处的锚点选择 |
