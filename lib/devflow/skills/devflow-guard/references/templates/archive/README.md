# 已完成能力归档目录

## 放什么

已完成能力的文档整包归档：该能力的设计、计划、偏差、测试全部文档移入该目录下的能力子目录。

```
<能力名>/
├── design.md
├── plan.md
├── deviation.md
└── testing.md
```

也可以把活跃目录里的原文件**直接按原名移入**，不必重命名——保持文件名与原始路径的对应关系，便于回查。

## 为什么不删除

归档的价值不是保存结论（结论已进代码与规则），而是保存**当时不知道什么**。
日后要判断「这个能力能不能改」时，知道当初有哪些盲区、哪些方案被排除过，比知道最终选了什么更有用。

## 与决策记录的边界

ADR **不进归档**，永远留在决策目录。原因：决策链靠编号顺序连续，移动会打断追溯。

## 归档动作

1. 该能力在总览表的状态**保持不变**（归档是存放位置，不是生命周期阶段，二者正交）
2. 各列路径更新为归档目录下的文件
3. 活跃目录中的文件移入归档目录
4. 不要删除归档内容
