## 关键路由边界

1. **「测试」与「覆盖率」的分界**：只说「跑测试」不触发；提到「覆盖」才触发。
2. **有效性质疑也触发**：「测试真的跑了吗」表面问测试，实质是问有效性。
3. **不承担写测试**：只采集，不生成测试代码。
