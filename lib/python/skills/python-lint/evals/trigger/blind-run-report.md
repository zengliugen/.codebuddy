## 局限

1. **NN-01 的分歧未消除，只是被显式记录**。这是「注释格式」一词本身的歧义，
   属词汇问题而非 `description` 缺陷；批次二引入注释技能后需重新评估二者边界。
2. **评审者同时是技能作者**，存在确认偏差风险。
3. **未做跨模型盲测**，单一评审者的判定不代表不同模型的语义分布。
4. **样本量小**：16 条不足以估计低频误触率。
