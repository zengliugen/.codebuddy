## 本轮改动说明

相对上一版，`description` 做了两处调整：

1. 增加「全中文、全角标点」的明确表述——这是用户新增强制要求。
2. 说明「首行标点因工具只认 ASCII 而改由本技能保证」——交代责任边界，
   避免用户以为跑 ruff 就够了。

## 局限

1. **评审者同时是技能作者**，存在确认偏差。
2. **未做跨模型盲测**：单一评审者的判定不代表不同模型的语义分布。
3. **样本量小**：16 条不足以估计低频误触率；结论只说明「主要路径无歧义」。
4. **标点诉求难以从一句话判断**：用户若只说「注释不太好」，不会联想到标点问题，
   需要追问才明确——这是自然语言本身的局限。
