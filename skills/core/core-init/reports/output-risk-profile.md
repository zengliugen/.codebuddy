# 输出风险画像（core-init）

本技能产出直接影响各技能能否定位到项目配置，风险点与缓解如下。

## 风险矩阵

| 风险 | 触发条件 | 影响 | 缓解 |
|------|---------|------|------|
| 覆盖已填写配置 | 用户已手工填写后再次运行 | 丢失人工内容 | **默认幂等**：已存在文件跳过；`--force` 须先确认 |
| 索引漂移 | 引擎升级后逻辑名/路径变更 | 生成到错误位置或漏生成 | 索引为唯一来源；脚本拒绝绝对路径；索引变更随引擎版本化 |
| 骨架误导 | 占位值被当作真实值使用 | 技能以错误配置运行 | 占位统一为 `<...>` 形式，显著区别于真实值；未填写时技能报错 |
| 静默失败 | 写权限不足等 | 配置未生成但未察觉 | 写入失败即报错退出（退出码 1），不静默继续 |
| 跨项目污染 | 索引被填入项目专有值 | 引擎在他项目失效 | 索引约定"纯约定 + 相对路径 + 占位值"；索引入库前人工审查 |
| 误判意图 | 未做状态检测就按入口措辞直接生成或改包 | 对已配置项目重复生成、误改用户选择 | **强制先跑 `--status`**；按 `actions` 生成选项，只呈现当前可行动作 |
| 误卸包 | 用户选择移除但未看清影响 | 已装能力消失、依赖方失效 | 移除前向用户确认链接清单；默认包由安装器拒绝；被依赖时须显式 `--force` |
| 手工改链接 | 绕过 `pack_install.py` 直接增删链接 | 安装状态与磁盘漂移 | 包管理一律经安装器，操作后以 `status` 复核一致 |

## 验收口径

- 幂等：连续运行两次，第二次全部"跳过"、无文件被改写。
- 完整：生成的 `files` 与 `rule_shells` 条目数与索引登记一致。
- 可定位：生成后各技能脚本能经索引读到配置（无"索引缺失/路径非法"报错）。
- 未填即报错：保留占位的配置在对应技能首次运行时报出**指向该配置**的可操作错误。
- 检测只读：`--status` 连续运行不改变任何文件与链接（可用 `git status` 空 diff 验证）。
- 意图闭环：每次调用都经过「检测 → 报告 → 询问 → 执行」，不替用户决定装/卸对象。

## 已知边界

- 本技能**不负责**填写具体项目值——「立即填写」阶段的探测质量取决于项目可探测信息的多寡；探测不到时必须询问用户。
- 本技能**不涉及**机器级配置（`models.json` / `settings.local.json`），它们留在 `.codebuddy` 根且不入库。
