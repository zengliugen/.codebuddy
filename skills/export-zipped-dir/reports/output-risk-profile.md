# 输出风险画像

## 风险矩阵

| 风险类别 | 严重度 | 概率 | 影响 | 缓解措施 |
|---------|--------|------|------|---------|
| 导出内容缺失（gitignore 误判） | 高 | 中 | 导出 zip 缺文件，目标项目迁移不完整 | git 模式用 `git ls-files` 权威过滤 + 导出后抽查 zip 内容 |
| 强制包含路径错误 | 中 | 低 | `--force` 指定的文件未打包或路径偏差 | `resolve_force` 路径归一化 + 导出后验证强制文件已包含 |
| 非 git 模式误跳敏感文件 | 中 | 低 | 未在 git 仓库内时全量导出含构建产物 | 跳过通用构建产物目录（`bin/`/`obj/`/`node_modules/` 等） |
| 迁移 patch 生成失败 | 高 | 中 | 目标项目无法精准迭代配置 | 基线扫描 + 路径重写 + 单个提交失败时告警继续 |
| patch 路径重写错误 | 高 | 低 | 目标项目 `git apply` 失败或应用到错误位置 | `filter_patch_by_codebuddy` 严格前缀校验 + CHANGES.md 排除 |
| 补丁应用冲突未识别 | 中 | 中 | 目标项目工作区被污染 | 分层冲突处理（apply→reverse-check→3way→手动） |
| 空提交误报失败 | 中 | 低 | 基线后无 .codebuddy 提交时错误退出 | 区分"无提交"与"生成失败"（修复 generate_migration_patches） |

## 输出质量维度

### 导出 zip 质量

可能的问题：
- zip 内相对路径结构被破坏（前缀丢失/错位）
- 被 gitignore 忽略的文件混入（git 模式）
- 强制包含文件缺失

防护措施：
- zip 内以源目录名为顶级前缀，保持相对路径
- 阶段三抽查 zip 内容，确认排除规则生效
- 输出文件总数 + 强制包含列表报告

### 迁移补丁质量

可能的问题：
- patch 内路径未统一为 `.codebuddy/` 前缀
- 非 `.codebuddy` 变更块混入 patch
- CHANGES.md 变更块重复（与导出覆盖冲突）

防护措施：
- `filter_patch_by_codebuddy` 前缀重写 + 非目标块剔除
- 显式排除 CHANGES.md 变更块
- 单个提交 patch 生成失败时告警并继续，不中断全部

### 补丁应用质量

可能的问题：
- 已应用的 patch 重复应用
- 冲突 patch 中断批量流程
- 已应用清单（`.patches-applied.log`）维护不当

防护措施：
- 已应用清单跳过 + `git apply --check --reverse` 自动识别
- "需手动解决"不中断，标记后继续
- 续传机制（处理冲突后写入清单重跑）

## 已知局限性

1. **非 git 模式退化依赖通用构建产物黑名单**：无法覆盖所有项目的自定义产物目录，需按需补充。
2. **patch 冲突层级依赖目标项目为 git 仓库**：非 git 仓库无法走 3way 合并，只能人工对照迁移。
3. **CHANGES.md 顺序依赖机器生成的可读性**：迁移影响列需人工结合 diff 评估。
