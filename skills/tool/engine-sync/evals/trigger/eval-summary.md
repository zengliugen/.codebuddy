# 触发评估摘要

|------|--------|-----------|
| Should Trigger | 10 | 100% |
| Should NOT Trigger | 14 | 100% |
| **总计** | **24** | **100%** |

## 触发设计

`description` 覆盖两类触发路径：

1. **显式更新并同步**："更新引擎到最新并同步项目侧"、"升级 .codebuddy 引擎"、"/engine-sync"。
2. **已更新、待落实**："引擎有更新看看要同步什么"、"子模块指针更新了项目侧还要做什么"。

## 关键路由边界

1. **首次初始化 vs 增量同步**：无项目侧目录、需要生成全部骨架 → `codebuddy-init`；
   已有项目侧内容、只需跟随引擎变化 → 本技能。
2. **纯查询 vs 落实同步**："引擎落后几个提交"只查询，不写盘，不触发本技能。
3. **改文件 vs 提交**：本技能不提交；提交走 `vcs-router`。
4. **技能工程**：新建/重构技能走 `yao-meta-skill`，本技能只提示"新增了技能"。
