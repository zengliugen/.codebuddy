## 关键路由边界

最容易被误路由的边界场景：

1. **通用提交请求 vs git 明确提交**: "帮我提交代码"等通用请求由 vcs-router 承接路由，本技能直接响应的场景收窄为 Git 明确上下文（"git commit"、"提交到 git"）与路由后执行。
2. **非 Git 上下文**: "svn commit"等非 Git 仓库请求由 vcs-router 检测后终止并提示，不应触发本技能。
3. **amend vs commit**: 用户说"修改提交信息"可能是指 amend，必须区分。
4. **非代码上下文**: "提交表单"/"提交报告"不应触发。

## 评估方法

- 人工审查：逐个验证每个案例的描述是否能被 `description` 正确路由。
- 盲测：随机打乱案例顺序，由独立评审者判断是否应触发。
- 对抗测试：构造边界模糊的输入，验证排除逻辑是否可靠。
